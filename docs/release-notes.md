# HoomNote 0.7.0

- Imports multiple Samsung Notes SDOCX files at once.
- Recursively imports Samsung Notes folders while preserving their hierarchy.
- Adds a best-effort importer for SDOCX files in the installed Samsung Notes
  Windows LocalState.
- Adds 0.1-step ink sizes and quick pen/highlighter size and color controls in
  the top toolbar.
- Reduces the visual size of tool and saved-preset icons while retaining
  touch-friendly hit targets.
- Keeps the live eraser patch visible until the updated page render is
  presented, eliminating the erase-completion flash.
